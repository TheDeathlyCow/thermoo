# Update to Minecraft 1.21.5

This is a first release for Minecraft 1.21.5, targeting `1.21.5-rc1`. This version is currently unstable, and should
only be used for early porting.

- Updated to Minecraft 1.21.5
- Removed all deprecated APIs, including the `EnvironmentController`, `TemperatureConverter`, and some methods
  of `ConfiguredTemperatureEffect`, and `TemperatureEffects`.
- Temporarily disabled gametests so that they can be rewritten at a later date
- The `EnvironmentCommand` and `TemperatureCommand` classes were made final and now have a private constructor. Other
  static-only classes like this will receive similar treatment soon.
